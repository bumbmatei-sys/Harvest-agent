# Eden reference screenshots (communities)

Reference for The Harvest's communities work: the design and the behaviour to match.
Captured by Matei from app.eden.so on 30 Oct 2026. These are reference images, not
assets: nothing in the app loads them.

A narrow icon rail on the left (Chat, Forum, Events, Products, Members, Messages, then
the community switcher), a section sidebar beside it, and the content in a rounded card
with a header bar ("Members · 3,913 people", "43 here now").
